# Guía Server — Laboratorio 302

## Estado del proyecto
Repositorio oficial de trabajo del proyecto **Guía Server**, correspondiente a la organización y documentación de la infraestructura del servidor del laboratorio 302.

Este repositorio centralizará la documentación del proyecto, los requisitos, la planificación, la presentación y los archivos del equipo. El estado actual es **organización inicial; todavía faltan evidencias para considerar completa la preparación del proyecto**.

## Problema y propósito
El trabajo parte de la necesidad académica de analizar la infraestructura de virtualización del laboratorio 302 y proponer una organización útil, segura y técnicamente justificada para las actividades académicas y los proyectos tecnológicos.

La auditoría técnica debe respaldarse con datos reales del servidor, como modelo del equipo, procesador, memoria RAM, almacenamiento, máquinas virtuales, consumo de recursos y limitaciones. Los datos que aún no estén documentados deben recopilarse; no se deben asumir ni inventar.
