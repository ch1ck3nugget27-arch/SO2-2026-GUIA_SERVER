# Guía de estudio · Servidor Lab 302 (Proxmox VE)
Sitio estático (HTML/CSS/JS), sin instalación ni dependencias.
## Ejecutar en VS Code
1. Descomprime el ZIP y abre la carpeta con `File > Open Folder`.
2. Instala la extensión **Live Server** (Ritwick Dey), clic derecho en `index.html` > *Open with Live Server*.
   (También funciona abriendo `index.html` directamente en el navegador.)
## Dónde editar
- `js/data.js`: todo el contenido (componentes, funcionalidades, ejercicios, enlaces).
- `css/style.css`: estilos · `js/app.js`: lógica de cada página.
