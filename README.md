# Guía de estudio · Servidor Lab 302 (Proxmox VE)

Sitio estático de apoyo para la guía del servidor.

## Cómo ejecutar
Abre la carpeta `docs/proyecto/` en Visual Studio Code y ejecuta `index.html` con la extensión Live Server. También puedes abrir el archivo directamente en el navegador.

## Estructura del repositorio
- `docs/proyecto/`: archivos del sitio de la guía (HTML, CSS y JavaScript).
- `docs/requisitos/`: documentación de requisitos.
- `docs/planificacion/`: planificación y cronograma Gantt.
- `docs/presentaciones/`: presentaciones del proyecto.
- `equipo/`: archivos de los integrantes.
