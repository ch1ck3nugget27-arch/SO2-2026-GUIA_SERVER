# Estado de requisitos para preparar el proyecto

Este archivo es una lista inicial de comprobación basada en la misión de organización del proyecto. No reemplaza el cuestionario oficial de Auditoría de Madurez que debe entregar el docente.

| Requisito | Estado observado | Evidencia o acción pendiente |
|---|---|---|

| Documento formal del proyecto en Word y/o PDF | Pendiente/no localizado en el repositorio revisado | Incorporar el documento aprobado en docs/proyecto/ |
| Requisitos del sistema documentados | Incompleto | Documentar requisitos funcionales y no funcionales con su fuente o justificación |
| Diagrama de Gantt disponible | Pendiente/no localizado | Subir la versión vigente a docs/planificacion/ |
| Presentación del proyecto disponible | Pendiente/no localizada | Subir el PowerPoint vigente a docs/presentaciones/ |
| Un TXT por integrante con nombre, apellido, grupo y rol | Incompleto | Completar datos faltantes de Lucas y el grupo de cada integrante |
| Issues para trabajo concreto | Incompleto al iniciar esta revisión | Crear tareas, definir evidencia y asignar responsables |
| GitHub Projects para seguimiento | Pendiente de verificar/configurar | Crear tablero y acordar estados de trabajo |

| Coherencia entre documento, README, Gantt e Issues | Pendiente de revisión final | Revisar antes del checkpoint con el docente |

## Criterio para cerrar un requisito
No marcar como completado solo porque exista una carpeta. Debe existir un archivo útil, actualizado y verificable, o un enlace a la evidencia correspondiente. Los datos técnicos del servidor y las decisiones del equipo no deben inventarse.
