## Reglas de seguimiento

- Asignar a cada tarea una persona con nombre y apellido antes de comenzar.
- Cada tarea debe tener evidencia verificable para cerrarse.
- Registrar el trabajo concreto como GitHub Issue y vincularlo al tablero del proyecto.
- Actualizar esta planificación cuando se acuerden cambios.
- No intervenir el servidor real sin autorización del responsable.
- Las actividades relacionadas con inventario y consumo dependen de la información que facilite el laboratorio.
